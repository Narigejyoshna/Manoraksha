# 🛡️ Manoraksha
**Digital Mental Health & Psychological Support System | SIH Project**

Manoraksha is a platform designed to provide students with a safe space to access mental health resources, track well-being, and connect with professionals.

## 🚀 Key Features
* **AI Chatbot:** Immediate conversational support for students.
* **Psychological Assessment:** Built-in tools for mental well-being evaluation.
* **Expert Booking:** System to schedule appointments with professionals.
* **Resource Hub:** Curated motivational and clinical content.

## 🛠 Tech Stack
* **Frontend:** HTML5, CSS3, JavaScript
* **Backend:** Node.js
* **API:** OpenAI Integration (for Chatbot)
